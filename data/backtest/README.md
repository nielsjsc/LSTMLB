# Backtest Data

Generated by [backtest_confidence.py](../../auto_train_models/scripts/backtest_confidence.py).

Contains retroactive predictions for the past 25 years (2000-2024), used to derive empirical confidence intervals for model predictions.

## Structure

- `batter/`, `pitcher/`, `fielding/`: Historical predictions by cutoff year
- `results/`: Error analysis and fitted confidence curves
